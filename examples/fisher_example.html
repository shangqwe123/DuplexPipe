DuplexPipe example

A 65-second excerpt of a two-speaker Fisher English telephone call. The input is the mono mixture and its speaker-attributed, time-stamped transcript. The output has one speaker per channel: speech the transcript marks as non-overlapped is copied, and only the overlapped spans (aqua) are regenerated.

Input · mono mixture
fisher_example.wav
Output · two channels
output/fisher_example.wav, use headphones

Hover to read the transcript at any moment; click to move both players there. With the chart focused, the arrow keys move the cursor. Regenerated time counts each speaker's channel separately and includes the 0.1 s widening around each overlap.
